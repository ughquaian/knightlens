# Third-Party Notices

KnightLens uses the following open-source software:

- **Stockfish / Stockfish.js** — browser chess engine, GPL-3.0. The project uses the Stockfish 18 lite single-threaded build from the `stockfish` npm package.
- **chess.js** — chess move generation, PGN parsing, and position handling.
- **Parse JavaScript SDK** — connection to Back4App for authentication and database storage.
- **Vite** — local development and production build tooling.

The Stockfish engine files are copied from `node_modules/stockfish/bin` during the build and are not authored by this project.
